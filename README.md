# Student Performance Data Analysis

A data analysis project focused on analyzing student performance and identifying useful insights from student marks data.

## Features
- Analyze student marks
- Calculate subject-wise performance
- Identify highest and lowest scores
- Analyze pass/fail performance
- Compare student performance
- Visualize data using charts

## Technologies Used
- Python
- Pandas
- Matplotlib
- Excel

## Purpose
This project was created to practice data cleaning, data analysis, and data visualization using student performance data.
